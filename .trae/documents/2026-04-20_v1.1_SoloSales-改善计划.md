2. 创建 `src/components/storefront/ProductGridClient.tsx`（保留客户端逻辑）
3. 将 `page.tsx` 改为 Server Component，数据从数据库获取

## 四、P2 级任务（安全与性能优化）

### 4.1 完善商品详情页

**问题**：商品详情页缺少多图切换、规格选择器、相关推荐。

**修改文件**：
- `src/app/[locale]/product/[id]/page.tsx` — 全面重构
- `src/components/product/ImageGallery.tsx` — 新建多图画廊组件
- `src/components/product/VariantSelector.tsx` — 新建规格选择器
- `src/components/product/RelatedProducts.tsx` — 新建相关推荐组件

**实施步骤**：
1. 创建 ImageGallery 组件（主图 + 缩略图列表 + 点击放大）
2. 创建 VariantSelector 组件（颜色/尺寸选择 + 价格联动）
3. 创建 RelatedProducts 组件（同品类推荐）
4. 重构商品详情页布局
5. 添加"加入购物车"和"立即购买"两个 CTA

---

### 4.2 添加紧迫感元素

**问题**：没有库存倒计时、限时优惠、实时购买通知。

**修改文件**：
- `src/components/product/ProductCard.tsx` — 添加销量标签
- `src/app/[locale]/product/[id]/page.tsx` — 添加倒计时
- `src/components/storefront/RecentPurchases.tsx` — 新建实时购买通知

**实施步骤**：
1. 在商品数据中添加 `stock` 和 `saleEndsAt` 字段
2. 创建倒计时组件（距离促销结束时间）
3. 创建 RecentPurchases 通知组件（随机显示"XX 刚购买了 YY"）
4. 库存低于阈值时显示"仅剩 X 件"

---

### 4.3 CSP 策略优化

**问题**：`next.config.ts` 中 CSP 使用 `'unsafe-inline' 'unsafe-eval'`，大幅削弱 XSS 防护。

**修改文件**：
- `next.config.ts` — 优化 CSP 配置
- `src/app/layout.tsx` — 添加 nonce script 标签

**实施步骤**：
1. 生成随机 nonce 并在每次请求时更新
2. 将 nonce 注入到 CSP script-src 指令
3. 在 layout.tsx 的 `<script>` 标签添加 `nonce` 属性
4. 测试所有功能不受影响（尤其是第三方脚本）

---

### 4.4 添加 CSRF 防护

**问题**：状态变更 API（订单创建、支付）缺少 CSRF Token 验证。

**修改文件**：
- `src/lib/csrf.ts` — 新建 CSRF 防护工具
- `src/app/api/orders/route.ts` — 添加 CSRF 验证
- `src/app/api/checkout/stripe/route.ts` — 添加 CSRF 验证
- `src/components/auth/AuthModal.tsx` — 在表单中添加 CSRF Token

**实施步骤**：
1. 创建 CSRF Token 生成和验证工具（使用 HMAC）
2. 在需要 CSRF 保护的 API 路由中添加验证中间件
3. 在前端表单中添加隐藏的 CSRF Token 字段
4. 测试 POST 请求在无 Token 时被拒绝
