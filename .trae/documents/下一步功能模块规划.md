# 电商功能增强规划

## 项目现状
SoloSales 是一个 TikTok 引流独立站，已完成：首页轮播图、购物车页面、商品详情页、结账弹窗（Stripe/PayPal 占位）、全局购物车状态管理。

当前问题：
- 结账弹窗简陋，缺乏用户认证流程
- 无订单追踪功能
- 无物流追踪功能
- 商品数据为静态 Mock

---

## 功能模块详细规划

### 模块 1：用户认证与结账流程

#### 1.1 触发机制
- 用户点击"立即购买"或"去结算"时，判断是否已登录
- 未登录：弹出登录/注册弹窗
- 已登录：直接进入结账流程

#### 1.2 用户注册与登录系统
**注册表单：**
- 用户名（username）
- 电子邮箱（email）
- 密码（password）
- 确认密码（confirmPassword）

**登录表单：**
- 电子邮箱（email）
- 密码（password）
- "忘记密码"链接

**技术实现：**
- 使用 NextAuth.js 实现认证
- Session 管理
- 密码加密存储（bcrypt）

#### 1.3 双重结账路径
**注册用户路径：**
1. 使用已有账户登录
2. 或完成新用户注册
3. 登录后自动进入结账确认页面

**访客结账路径：**
1. 点击"访客结账"入口
2. 填写必填信息：姓名、电话、邮箱、收货地址
3. 无需创建账户即可完成购买

#### 1.4 订单状态追踪系统
**订单状态流转：**
```
待支付 → 已支付 → 已发货 → 运输中 → 已签收
                  ↓
               已取消
```

**用户端订单追踪：**
- 订单列表页面（`/orders`）
- 订单详情页（`/orders/[id]`）
- 显示当前状态、时间线、快递信息

### 模块 2：结账弹窗 UI/UX 优化

#### 2.1 现代化视觉设计
- 渐变背景或柔和阴影
- 圆角卡片设计
- 适当的内边距和间距
- 品牌色彩保持一致

#### 2.2 表单设计与验证
**必填字段：**
- 收货人姓名
- 联系电话
- 收货地址（省/市/区 + 详细地址）
- 邮箱（用于订单通知）

**实时验证：**
- 邮箱格式验证
- 电话号码格式验证
- 地址完整性检查

#### 2.3 加载状态与错误处理
- 提交按钮显示加载动画
- 网络错误友好提示
- 表单错误即时反馈
- 支付失败错误恢复

#### 2.4 交互优化
- Tab 切换：登录 / 注册 / 访客结账
- 记住用户信息（localStorage）
- 密码可见/隐藏切换

---

### 模块 3：物流追踪功能

#### 3.1 管理端控制
**订单管理后台：**
- 查看所有订单列表
- 单个订单物流信息录入（快递公司、运单号）
- 订单状态更新（待支付/已支付/已发货/已完成/已取消）
- 批量操作支持

**物流追踪开关：**
- 全局开关：控制是否启用物流追踪功能
- 单订单开关：可单独禁用某订单的物流追踪

#### 3.2 物流 API 集成
- 接入第三方物流 API（如 快递100、Trackingmore）
- 支持主流快递公司
- 自动获取物流状态更新

#### 3.3 用户端物流展示
**订单详情页物流区块：**
- 快递公司名称 + 运单号
- 点击复制运单号
- 物流状态时间线
- 预计送达时间

**物流状态节点：**
- 已发货：商品已发出
- 运输中：包裹运输中
- 派送中：正在派送
- 已签收：已签收/拒收

#### 3.4 邮件通知
**触发时机：**
- 订单确认（已支付）
- 商品已发货
- 物流状态更新
- 包裹已签收

## 技术实现方案

### 新增文件结构
```
src/
├── app/
│   ├── orders/                    # 订单相关
│   │   ├── page.tsx             # 订单列表
│   │   └── [id]/page.tsx        # 订单详情
│   ├── auth/                     # 认证相关
│   │   └── page.tsx             # 登录/注册页
│   └── api/
│       ├── auth/[...nextauth]/   # NextAuth API
│       ├── orders/              # 订单 API
│       └── logistics/           # 物流 API
├── components/
│   ├── auth/
│   │   ├── LoginForm.tsx
│   │   ├── RegisterForm.tsx
│   │   └── GuestCheckoutForm.tsx
│   ├── checkout/
│   │   └── EnhancedCheckoutModal.tsx  # 新的结账弹窗
│   └── logistics/
│       └── TrackingTimeline.tsx
└── lib/
    └── auth.ts                  # NextAuth 配置
```

### 依赖安装
- `next-auth` - 用户认证
- `bcryptjs` - 密码加密
- `react-hook-form` + `zod` - 表单验证
- `@tanstack/react-query` - 数据请求管理（可选）

### 数据库模型扩展（Prisma）
```prisma
model User {
  id        String   @id @default(cuid())
  email     String   @unique
  password  String
  name      String?
  orders    Order[]
}

model Order {
  id              String   @id @default(cuid())
  userId          String?
  user            User?    @relation(fields: [userId], references: [id])
  status          String   @default("pending")
  totalAmount     Float
  shippingAddress Json
  contactInfo     Json
  trackingNumber  String?
  logisticsEnabled Boolean @default(true)
  createdAt       DateTime @default(now())
  updatedAt       DateTime @updatedAt
}
```
