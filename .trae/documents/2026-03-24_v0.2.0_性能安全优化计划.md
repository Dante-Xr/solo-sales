# SoloSales v0.2 性能与安全优化计划

## 版本信息
- **版本号**: v0.2
- **制定日期**: 2026-03-24
- **当前版本**: v0.1
- **优化类型**: 性能优化 + 安全性增强

---

## 一、问题汇总

### 1.1 安全性问题 (P0-P1)

| 优先级 | 问题 | 影响范围 |
|--------|------|----------|
| P0 | 密码明文存储 (`/api/auth/register`) | 用户数据安全 |
| P0 | 环境变量缺乏验证，Mock 值可能泄露 | 生产环境安全 |
| P0 | 缺少 Rate Limiting 中间件 | API 被暴力攻击 |
| P1 | API 路由缺少 CORS 配置 | 支付 API 被恶意调用 |
| P1 | 缺少安全响应头 (CSP, HSTS 等) | XSS/点击劫持风险 |
| P1 | 缺少 API 参数验证 (Zod) | 注入攻击风险 |

### 1.2 性能问题 (P1-P2)

| 优先级 | 问题 | 影响范围 |
|--------|------|----------|
| P1 | 图片缺少 AVIF/WebP 格式支持 | 加载速度 |
| P1 | 缺乏 Bundle 大小监控 | 打包体积失控 |
| P2 | Context 缺少性能优化 | 不必要的重渲染 |
| P2 | 静态数据在组件内重新创建 | 内存浪费 |
| P2 | 缺少预加载/预获取策略 | 导航体验 |

## 二、修改计划

### Phase 1: 安全修复 (P0)

#### Task 1.1: 密码加密实现
**文件**: `src/app/api/auth/register/route.ts`

**修改内容**:
1. 导入 `bcryptjs`
2. 使用 `bcrypt.hash()` 加密用户密码
3. 密码强度验证 (最少8位，包含字母和数字)

**验证标准**: 存储的密码为 hash 值，非明文

---

#### Task 1.2: 环境变量验证增强
**文件**: `src/lib/redis.ts`, `src/app/api/checkout/stripe/route.ts`

**修改内容**:
1. 添加环境变量存在性检查
2. 生产环境必须提供真实值，禁止使用 Mock
3. 缺少必需环境变量时抛出明确错误

**新增文件**: `src/lib/env-validator.ts` - 统一环境变量验证

---

#### Task 1.3: Rate Limiting 中间件
**新增文件**: `src/middleware/rate-limit.ts`

**修改内容**:
1. 实现基于 IP 的请求频率限制
2. 注册 API: 5分钟内心注册不超过 3 次
3. 支付 API: 5分钟内心支付不超过 10 次
4. 搜索 API: 1分钟内不超过 30 次

**验证标准**: 超限返回 429 状态码

---

### Phase 2: API 安全增强 (P1)

#### Task 2.1: Zod 请求验证
**新增文件**: `src/lib/validators.ts`

**修改内容**:
1. 为所有 API 创建 Zod Schema
2. `/api/auth/register`: 验证 email, password, name
3. `/api/checkout/stripe`: 验证 productId, price, quantity
4. `/api/checkout/paypal`: 验证 price, quantity

**验证标准**: 无效请求返回 400 状态码和具体错误信息

---

#### Task 2.2: CORS 配置
**文件**: 支付相关 API

**修改内容**:
1. 配置允许的源 (环境变量控制)
2. 仅允许 POST 方法
3. 限制可访问的 header

---

#### Task 2.3: 安全响应头
**文件**: `next.config.ts`

**修改内容**:
```typescript
securityHeaders: [
  { key: 'X-DNS-Prefetch-Control', value: 'on' },
  { key: 'Strict-Transport-Security', value: 'max-age=63072000; includeSubDomains; preload' },
  { key: 'X-Frame-Options', value: 'SAMEORIGIN' },
  { key: 'X-Content-Type-Options', value: 'nosniff' },
  { key: 'Referrer-Policy', value: 'origin-when-cross-origin' },
  { key: 'Content-Security-Policy', value: "default-src 'self'; script-src 'self' 'unsafe-inline'; style-src 'self' 'unsafe-inline';" },
]
```

---

### Phase 3: 性能优化 (P1-P2)

#### Task 3.1: Next.js 图片优化配置
**文件**: `next.config.ts`

**修改内容**:
1. 启用 AVIF/WebP 自动转换
2. 配置响应式图片尺寸
3. 添加 `optimizePackageImports` 优化 lucide-react

---

#### Task 3.2: Bundle 分析配置
**文件**: `next.config.ts`, `package.json`

**修改内容**:
1. 安装 `@next/bundle-analyzer`
2. 配置 bundle 分析脚本
3. 设置包大小阈值警告

**新增脚本**:
```json
"analyze": "ANALYZE=true next build"
```

---

#### Task 3.3: Context 性能优化
**文件**: `src/context/CartContext.tsx`, `src/context/WishlistContext.tsx`

**修改内容**:
1. 使用 `useMemo` 缓存计算值 (cartTotal, cartCount)
2. 使用 `React.memo` 优化子组件
3. 拆分大型 Context

---

#### Task 3.4: 静态数据优化
**文件**: `src/app/page.tsx`, `src/components/storefront/HomeCarousel.tsx`

**修改内容**:
1. 将 `FEATURED_PRODUCTS` 移到组件外部作为常量
2. 使用 `useMemo` 缓存派生数据

---

### Phase 4: 代码质量 (可选)

#### Task 4.1: 添加 ESLint 安全插件
**文件**: `eslint.config.mjs`

**修改内容**:
1. 添加 `eslint-plugin-security`
2. 启用安全规则检查
