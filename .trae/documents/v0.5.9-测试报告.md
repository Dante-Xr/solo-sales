#### ⚠️ 待修复问题

1. **NextAuth 登录绕过漏洞**
   ```typescript
   // src/app/api/auth/[...nextauth]/route.ts:38
   const isValid = credentials.password === "test123" // 直接明文比较
   ```
   **问题**: 绕过了 bcrypt 验证，DEV_USERS 中存储的 bcrypt hash 完全无效
   **修复**: 使用 bcrypt.compare() 验证

2. **购物车状态丢失**
   ```typescript
   // src/context/CartContext.tsx
   const [cart, setCart] = useState<CartItem[]>([]) // 无持久化
   ```
   **问题**: 页面刷新后购物车数据丢失
   **修复**: 添加 localStorage 持久化
