# 首页重构计划 v0.8.0

## 目标
将商城首页从移动端优先设计改为 **PC 端优化布局**，参考 Shopify Zap Theme (Portable 预设) 的极简现代美学风格。

## Shopify Zap Theme 设计特点分析
1. **极简布局** - 大量留白，bold 字体排版
2. **全宽区块** - Full-width sections，干净利落的网格
3. **现代美学** - Contemporary aesthetic，精致排版
4. **策略性结构** - Strategic structure，突出品牌

## 执行步骤

### 1. 重构首页布局容器
- 移除 `max-w-md` 移动端限制
- 创建响应式 PC 布局 (最大宽度 1280px 或 1440px)
- 使用 CSS Grid/Flexbox 实现现代化布局

### 2. 重构 Header 导航栏
- 水平导航布局替代垂直堆叠
- Logo 居左，导航菜单居中，操作按钮居右
- 搜索框集成到导航栏
- 添加 Desktop 专属导航项

### 3. 重构 Hero Section
- 全宽轮播图作为 Hero
- 大标题 + 副标题叠加在图片上
- 现代化 CTA 按钮设计
- 添加特色图标区域

### 4. 重构商品展示区域
- 4 列网格布局替代 2 列
- 更大的商品卡片
- 悬停效果增强
- 现代化标签设计

### 5. 添加 Feature/Benefits 区块
- 4 列特性介绍区域
- 图标 + 标题 + 描述
- 与 Zap Theme "Clean, Contemporary Aesthetic" 风格一致

### 6. 添加 Footer 区域
- 多列链接布局
- Newsletter 订阅区域
- 社交媒体链接

### 7. 响应式适配
- 桌面端 (≥1024px): PC 布局
- 平板端 (768px-1023px): 适配布局
- 移动端 (<768px): 保持移动端体验

| 文件 | 变更内容 |
