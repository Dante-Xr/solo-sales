## 二、🔴 高优先级问题

### P-001: N+1 查询风险

**位置**: `src/app/api/products/route.ts:94-110`

**问题描述**:
```typescript
const [list, total] = await Promise.all([
  prisma.product.findMany({
    include: {
      category: { select: { id: true, name: true } },
      _count: { select: { orderItems: true } },  // ✅ 正确
      reviews: true  // ❌ 可能导致 N+1
    },
  }),
])
```

**性能影响**:
- 100 个商品 × 10 个评价 = 1000 次数据库查询
- 响应时间从 ~50ms 增加到 ~2000ms

**修复建议**:
```typescript
// 方案 1: 只返回数量
include: {
  category: true,
  _count: { select: { reviews: true } }
}

// 方案 2: 使用 @cursor 做分页加载
```

### P-002: 缺失数据库索引

**位置**: `prisma/schema.prisma`

**问题描述**:
常见查询模式缺少复合索引：

```prisma
// 当前只有单列索引
@@index([categoryId])
@@index([isPublished])

// 缺失的复合索引
// 1. 分类+发布状态+时间 (管理后台常用)
@@index([categoryId, isPublished, createdAt])

// 2. 订单用户+状态 (订单列表常用)
@@index([userId, status])

// 3. 废弃购物车查询
@@index([status, createdAt])
```

**性能影响**:
- 10 万商品时，分类筛选从 5ms 增加到 500ms
- 全表扫描导致数据库 CPU 飙升

**修复建议**:
```prisma
model Product {
  // ... 其他字段
  @@index([categoryId, isPublished, createdAt])
}

model Order {
  // ... 其他字段
  @@index([userId, status])
}

model AbandonedCart {
  // ... 其他字段
  @@index([status, createdAt])
}
```

### P-003: 缓存键命名冲突

**位置**: `src/lib/cache.ts`

**问题描述**:
```typescript
const CACHE_KEYS = {
  FEATURED_PRODUCTS: "cache:get:products:featured",
  // 与其他系统可能冲突
  PRODUCT_LIST: "cache:product:list:${params}",
}
```

**问题**:
- 键前缀过于通用
- 无命名空间隔离
- 与其他微服务冲突

**修复建议**:
```typescript
const CACHE_KEYS = {
  FEATURED_PRODUCTS: "solo:products:featured",  // 添加项目前缀
  PRODUCT_LIST: (params: string) => `solo:products:list:${params}`,
  CART: (userId: string) => `solo:cart:${userId}`,
  ADMIN_PERMISSIONS: (adminId: string) => `solo:admin:permissions:${adminId}`,
}
```

### P-005: Prisma 实例重复创建

**位置**: `src/lib/prisma.ts`

**问题描述**:
```typescript
// prisma.ts
const prisma = new PrismaClient()

// adminAuth.ts:18
const prisma = new PrismaClient()  // 重复创建实例
```

**问题**:
- 虽然 Prisma 有连接池，但显式创建多个实例可能浪费资源
- 热重载时可能创建过多连接

**修复建议**:
```typescript
// 使用单例模式
let prisma: PrismaClient

declare global {
  var prisma: PrismaClient | undefined
}

if (process.env.NODE_ENV === "production") {
  prisma = new PrismaClient()
} else {
  if (!global.prisma) {
    global.prisma = new PrismaClient()
  }
  prisma = global.prisma
}

export { prisma }
```

### P-006: Admin 权限缓存未清理

**位置**: `src/lib/adminAuth.ts`

**问题描述**:
权限变更后，缓存可能未及时更新：
```typescript
export async function invalidatePermissionCache(adminId: string): Promise<void> {
  const cacheKey = `admin:permissions:${adminId}`
  await cacheDel(cacheKey)
}
```

**问题**:
- 如果 Redis 删除失败，缓存会过期
- 无缓存版本控制

**修复建议**:
```typescript
// 使用缓存版本号
const CACHE_VERSION = "v1"

export async function invalidatePermissionCache(adminId: string): Promise<void> {
  const cacheKey = `admin:permissions:${CACHE_VERSION}:${adminId}`
  await cacheDel(cacheKey)
  // 递增版本号使旧缓存自动失效
  await cacheSet("admin:permissions:version", CACHE_VERSION + 1, Infinity)
}
```

### P-007: 缺少请求超时配置

**位置**: 全局

**问题描述**:
API 请求和数据库查询无超时配置：
```typescript
// 无超时
const orders = await prisma.order.findMany({...})
```

**问题**:
- 数据库慢查询无超时限制
- 第三方 API 无超时限制
- 可能导致连接池耗尽

**修复建议**:
```typescript
// Prisma 查询超时
prisma.$connect().then(() => {
  prisma.$executeRaw`SET statement_timeout = '30s'`
})

// fetch 超时
const controller = new AbortController()
setTimeout(() => controller.abort(), 10000)
fetch(url, { signal: controller.signal })
```
