## 二、🔴 高风险问题 (必须修复)

### S-001: NextAuth 明文密码比较漏洞

**严重性**: 🔴 严重
**CVSS 评分**: 9.1
**位置**: `src/app/api/auth/[...nextauth]/route.ts:38`

**问题描述**:
```typescript
// 第 38 行：直接比较明文密码
const isValid = credentials.password === "test123"
```
密码验证完全绕过了 bcrypt 机制，DEV_USERS 中存储的密码 hash 变成无效。

**攻击场景**:
1. 攻击者注册账户
2. 攻击者无论输入正确或错误密码都可能登录成功
3. 攻击者可以冒充任何已注册用户

**修复建议**:
```typescript
import bcrypt from "bcryptjs"

// 修改第 38 行为
const isValid = await bcrypt.compare(credentials.password, user.password)
```

**修复优先级**: P0 - 立即修复

### S-002: 并发库存超卖漏洞

**严重性**: 🔴 严重
**CVSS 评分**: 8.5
**位置**: `src/app/api/orders/route.ts:99-112`

**问题描述**:
订单创建时库存扣减是非原子操作：
```typescript
// 第 106-109 行
const product = await prisma.product.update({
  where: { id: productId },
  data: { stock: { decrement: quantity } }
})
```
在高并发场景下，多个请求可能同时读取到相同的库存值，导致超卖。

**攻击场景**:
1. 商品库存为 1
2. 100 个并发请求同时下单
3. 所有请求都读到 stock = 1
4. 100 个订单成功创建，但库存变为负数或仍为 1

**修复建议**:
```typescript
// 使用乐观锁
const product = await prisma.$transaction(async (tx) => {
  const p = await tx.product.findUnique({
    where: { id: productId },
    select: { stock: true }
  })

  if (!p || p.stock < quantity) {
    throw new Error("库存不足")
  }

  return tx.product.update({
    where: {
      id: productId,
      stock: { gte: quantity } // 乐观锁条件
    },
    data: { stock: { decrement: quantity } }
  })
})
```

**修复优先级**: P0 - 立即修复

**位置**: `.env.example`, `.env.local`

### S-004: SQL 注入风险 (Next.js)

**严重性**: 🔴 高
**CVSS 评分**: 7.5
**位置**: `src/app/api/products/route.ts:80-84`

**问题描述**:
```typescript
where.OR = [
  { name: { contains: keyword, mode: "insensitive" } },
  { description: { contains: keyword, mode: "insensitive" } },
]
```
虽然 Prisma 使用参数化查询，但 `mode: "insensitive"` 在某些边缘情况下可能有问题。

**修复建议**:
```typescript
// 添加输入 sanitization
const sanitizedKeyword = keyword
  .replace(/[%_]/g, '\\$&') // 转义 LIKE 特殊字符
  .slice(0, 100) // 限制长度

where.OR = [
  { name: { contains: sanitizedKeyword, mode: "insensitive" } },
  { description: { contains: sanitizedKeyword, mode: "insensitive" } },
]
```

**修复优先级**: P1 - 本周修复

## 三、🟡 中风险问题 (建议修复)

### S-005: 金额精度问题

**严重性**: 🟡 中
**位置**: `prisma/schema.prisma` - Order, Product, Payment 模型

**问题描述**:
```prisma
totalAmount Float    // 浮点数精度问题
price       Float
```

**风险**: 金融计算 `0.1 + 0.2 = 0.30000000000000004`

**修复建议**:
```prisma
totalAmount Decimal @db.Decimal(10, 2)
price       Decimal @db.Decimal(10, 2)
```
