## 需求分析

### 用户需求 1：用户图标 + 悬浮菜单
在 Header 右侧添加用户图标，提供以下功能：

| 状态 | 显示 | 点击行为 |
|------|------|----------|
| 未登录 | 用户图标（灰色） | 弹出登录选项菜单 |
| 已登录 | 用户头像/图标（彩色） | 弹出用户菜单 |

### 悬浮菜单选项
| 选项 | 说明 | 路由 |
|------|------|------|
| 个人资料 | 用户信息管理 | `/profile` (待创建) |
| 我的订单 | 订单列表 | `/orders` |
| 管理后台 | 仅管理员可见 | `/admin` |
| 退出登录 | 清除会话 | - |

---

## 实现方案

### 方案 A：在现有 Header 基础上扩展（推荐）
在 `page.tsx` 的 Header 中添加用户图标和相关逻辑。

**优点：** 改动最小，快速实现
**缺点：** 代码较分散

### 方案 B：创建 Header 组件
创建独立的 `UserMenu.tsx` 组件，在各页面复用。

**优点：** 组件化、可复用
**缺点：** 需要更多文件

---

## 推荐执行计划

### 阶段 1：用户菜单组件（推荐方案 B）
1. 创建 `src/components/storefront/UserMenu.tsx`
   - 使用 next-auth 的 `useSession` 判断登录状态
   - 使用 `@radix-ui/react-dropdown-menu` 或自定义悬浮菜单
   - 显示用户头像（已登录）/ 用户图标（未登录）

2. 菜单内容：
   - 未登录：登录 / 注册
   - 已登录：个人资料、我的订单、[管理后台]、退出登录

### 阶段 2：集成到首页
1. 修改 `page.tsx` Header
2. 添加用户图标到购物车左侧

### 阶段 3：个人资料页面（可选扩展）
1. 创建 `src/app/profile/page.tsx`
2. 显示/编辑用户信息

---

## 技术要点

- 使用 `Avatar` UI 组件（已存在）
- 使用 `useSession` 获取登录状态
- 使用 `signOut` 退出登录
- 使用 `DropdownMenu` 或自定义悬浮层实现弹出菜单
