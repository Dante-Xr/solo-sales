# Public Demo Page Spec

## Why

当前项目只能在本地开发环境中运行（localhost:3000），无法方便地向外部人员（如潜在客户、合作伙伴）展示。需要创建一个可以公开访问的演示页面，让外部人员无需安装配置即可体验产品功能。

## What Changes

- 新增 `/demo` 路由作为公开演示页面
- 演示页面包含核心功能展示：商品浏览、搜索、购物车、结账流程
- 移除敏感功能（管理后台、真实下单）
- 添加"演示模式"标识，明确告知用户这是演示环境
- 演示数据使用预设的 Mock 数据，无需后端

## Impact

- Affected specs: storefront-features (扩展)
- Affected code:
  - `src/app/demo/page.tsx` (新建)
  - `src/app/page.tsx` (参考布局)
  - `src/components/storefront/` (复用现有组件)

## ADDED Requirements

### Requirement: Public Demo Page

演示页面 SHALL 包含以下核心功能：

#### Scenario: 访客访问演示页面
- **WHEN** 外部用户访问 `/demo` 路由
- **THEN** 显示完整的电商演示界面，包括首页轮播、商品列表、搜索框、用户菜单

#### Scenario: 演示模式标识
- **WHEN** 用户访问演示页面
- **THEN** 在页面顶部显示"演示模式"横幅，提示用户这是体验环境

#### Scenario: 商品浏览
- **WHEN** 用户浏览演示页面
- **THEN** 可以查看轮播图、商品列表、价格信息

#### Scenario: 搜索功能
- **WHEN** 用户在搜索框输入关键词
- **THEN** 显示搜索历史和热搜词推荐

#### Scenario: 购物车操作
- **WHEN** 用户点击"加入购物车"
- **THEN** 商品添加到购物车，可以查看购物车内容

#### Scenario: 结账流程（只读）
- **WHEN** 用户点击"立即购买"或"去结算"
- **THEN** 显示提示"这是演示环境，不支持真实下单"

### Requirement: Demo Data

演示页面 SHALL 使用预设的 Mock 数据：

- 3个演示商品（带图片、价格、描述）
- 预置的搜索历史和热搜词
- 购物车数据仅存在 localStorage（不提交）

## MODIFIED Requirements

### Requirement: 现有组件复用

现有 storefront 组件（HomeCarousel、SearchBox、商品卡片等）SHALL 在演示页面中复用，无需重复开发。

## REMOVED Requirements

无

## Technical Considerations

1. **路由**: `/demo` 独立路由，不影响原有 `/` 首页
2. **组件复用**: 直接 import 现有 storefront 组件
3. **状态隔离**: 演示页面的购物车等状态与主站隔离
4. **无敏感操作**: 不调用真实 API，不展示管理功能
5. **响应式**: 移动端优先，与现有设计一致
