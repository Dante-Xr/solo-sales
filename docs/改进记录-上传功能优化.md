## 🐛 已修复的问题

### 问题1: 嵌套按钮警告
**错误**:
```
<button> cannot be a descendant of <button>
```

**原因**: DialogClose 组件本身是 button，内部又包含了 Button 组件

**解决方案**:
```tsx
// 修复前
<DialogClose>
  <Button variant="ghost" size="icon-sm">
    <X />
  </Button>
</DialogClose>

// 修复后
<DialogClose asChild>
  <button className="rounded-md p-2 hover:bg-accent">
    <X />
  </button>
</DialogClose>
```

### 问题2: 上传卡在 90%
**原因**: 可能是 API 响应慢或错误未正确处理

**解决方案**:
1. 添加 console.log 调试
2. 确保 clearInterval 在正确时机调用
3. 先完成进度条（100%），再处理结果
4. 添加 500ms 延迟显示最终状态

## 🔍 调试指南

### 查看上传日志
打开浏览器控制台（F12），上传文件时会看到：

```
开始上传到: /api/payment/proof
上传响应状态: 200
上传结果: {success: true, status: 'OCR_MATCHED', ...}
```

### 常见问题排查

#### 问题: 上传一直停在 90%
**检查**:
1. 浏览器控制台是否有错误
2. Network 标签中 `/api/payment/proof` 请求状态
3. 服务器日志是否有异常

**解决**:
- 如果是 API 超时：增加超时时间
- 如果是 OCR 服务问题：检查 OCR 服务配置
- 如果是网络问题：检查服务器连接

#### 问题: 预览图片不显示
**检查**:
1. FileReader 是否成功读取
2. uploadedImage 状态是否设置
3. Image 组件的 src 是否有效

#### 问题: 上传后没有反应
**检查**:
1. API 返回的数据格式
2. uploadResult 状态是否正确设置
3. 条件渲染逻辑是否正确

## 🎯 后续优化建议

### 1. 真实上传进度
使用 XMLHttpRequest 或 axios 获取真实进度：
```typescript
const xhr = new XMLHttpRequest()
xhr.upload.addEventListener('progress', (e) => {
  const percent = (e.loaded / e.total) * 100
  setUploadProgress(percent)
})
```

### 2. 图片压缩
大图片上传前自动压缩：
```typescript
import imageCompression from 'browser-image-compression'

const compressed = await imageCompression(file, {
  maxSizeMB: 1,
  maxWidthOrHeight: 1920
})
```

### 3. 拖拽上传
支持拖拽文件到上传区域：
```tsx
<div
  onDrop={handleDrop}
  onDragOver={handleDragOver}
>
  拖拽图片到这里
</div>
```

### 4. 多图上传
支持一次上传多张凭证：
```tsx
<input
  type="file"
  multiple
  accept="image/*"
/>
```

### 5. OCR 结果显示
显示 OCR 识别出的金额和置信度：
```tsx
<div>
  识别金额: ${ocrAmount}
  置信度: {confidence}%
</div>
```
