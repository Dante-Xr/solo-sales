# #7 Figma Enhance 后台与全站收口

## 决策

- 保留现有后台信息密度、表格列数、筛选、分页、导入和 RBAC 行为；只迁移视觉与交互状态。
- 发布验收覆盖共享容器及代表性页面：仪表盘、列表、表单/知识库、导入或支付凭证弹窗、暗色模式和移动抽屉。
- 动效仅用于抽屉、弹窗、标签、hover、加载与图表过渡；不延迟表格或筛选数据。
- 暗色模式主要文字与操作至少达到 WCAG AA 对比目标；状态色保持成功、警告、失败和信息语义。

## 实施范围

- 统一 `AdminLayout`、面包屑、标签页、表格、表单、弹窗、图表与空状态的 Figma Enhance token、边框、圆角和 focus/hover 规则。
- 不新增参考目录未实际使用的框架依赖，不部署生产。
