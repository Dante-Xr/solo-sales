# v1.7.2 Personal QR Code Payment - Testing Guide

## Overview

v1.7.2 实现了个人/商家收款码支付功能（临时过渡方案）。

**⚠️ 重要提示**: 这是一个临时方案，依赖人工审核，适合日订单量 < 50 的早期阶段。

## Setup

### 1. Environment Variables

确保 `.env` 文件包含以下配置：

```env
# Database
DATABASE_URL="postgresql://..."

# SMTP (邮件通知)
SMTP_HOST=smtp.example.com
SMTP_PORT=465
SMTP_USER=noreply@example.com
SMTP_PASS=your_password

# Site
SITE_NAME=SoloSales
DOMAIN=yourdomain.com
NEXT_PUBLIC_URL=http://localhost:3000
```

### 2. Database Migration

```bash
npx prisma db push
npx ts-node prisma/seed-qrcode.ts
```

### 3. Upload QR Code Images

将收款码图片放到 `public/qrcodes/` 目录：
- `public/qrcodes/alipay.png` - 支付宝收款码
- `public/qrcodes/wechat.png` - 微信收款码

## Known Issues

1. **OCR准确率**: Tesseract.js对中文识别可能不够准确
   - 解决方案：收集真实样本，调整识别参数

2. **image-hash在Jest中失败**: 已改用SHA-256
   - 影响：重复检测基于文件内容而非视觉相似度

3. **Next.js API测试复杂**: 跳过单元测试
   - 解决方案：依赖手动测试和E2E测试

4. **缺少认证集成**: API未验证管理员权限
   - 待办：集成better-auth后添加权限检查

## Performance Notes

- OCR识别耗时：2-5秒（首次需下载语言包）
- 图片哈希计算：<1秒
- 邮件发送：1-2秒
