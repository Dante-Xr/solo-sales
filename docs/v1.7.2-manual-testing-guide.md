### 步骤 1.5：验证数据库记录

**在终端运行**：
```bash
node -e "
const { PrismaClient } = require('@prisma/client');
const prisma = new PrismaClient();
prisma.paymentProof.findFirst({
  where: { orderId: 'cmqy1ol460002fb2n7z6cwa5o' }
}).then(proof => {
  console.log('支付凭证记录:');
  console.log('  状态:', proof.status);
  console.log('  OCR金额:', proof.ocrAmount);
  console.log('  置信度:', proof.ocrConfidence);
  console.log('  创建时间:', proof.createdAt);
  prisma.\$disconnect();
});
"
```

**预期输出**：
```
支付凭证记录:
  状态: OCR_MATCHED
  OCR金额: 24.99
  置信度: 0.95 (或其他值)
  创建时间: 2026-06-29T...
```
