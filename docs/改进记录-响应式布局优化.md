## 🔧 技术实现

### 文件结构
```
src/app/[locale]/payment/qrcode/[orderId]/
├── page.tsx                    # 主页面（数据加载）
└── PaymentPageLayout.tsx       # 布局组件（响应式）
```

### 响应式策略

#### 1. Tailwind 断点
- `hidden lg:block` - PC端显示
- `lg:hidden` - 移动端显示
- 断点：`lg = 1024px`

#### 2. 组件复用
所有子组件支持 `compact` 参数：
```typescript
<OrderInfoCard compact={isMobile} />
<QRCodeCard compact={isMobile} />
```

#### 3. 布局技术
- **PC端**: CSS Grid（3列，2:1比例）
- **移动端**: Flexbox（垂直堆叠）
- **固定侧边栏**: `sticky top-8`

## ✨ 用户体验优化

### PC端优势
1. **一屏展示** - 所有信息无需滚动
2. **收款码固定** - 扫码时可同时查看订单
3. **大尺寸元素** - 易于阅读和操作
4. **多列布局** - 信息组织清晰

### 移动端优势
1. **全宽显示** - 充分利用屏幕空间
2. **垂直滚动** - 符合移动端浏览习惯
3. **紧凑布局** - 减少滚动距离
4. **大触控目标** - 按钮易于点击

## 🎯 设计原则

### 1. 移动优先
- 基础样式针对移动端
- 使用 `lg:` 前缀添加PC端样式

### 2. 渐进增强
- 移动端功能完整
- PC端提供更好的体验

### 3. 一致性
- 相同的颜色系统
- 相同的交互反馈
- 相同的文案和提示

### 4. 性能
- 组件按需加载
- 图片懒加载
- 避免重复渲染

## 📈 性能指标

### 目标
- **首次内容绘制(FCP)**: < 1.5s
- **最大内容绘制(LCP)**: < 2.5s
- **累积布局偏移(CLS)**: < 0.1
- **首次输入延迟(FID)**: < 100ms

### 优化措施
- ✅ 图片使用 Next.js Image 优化
- ✅ 收款码使用 `priority` 优先加载
- ✅ 避免布局偏移（固定尺寸）
- ✅ 组件拆分减少重渲染
