# v1.7.8 Figma Enhance 用户端迁移

## 交付内容

- 全局语义 token 迁移为暖灰画布、深海军蓝、酒红强调、白色卡片与可读的暗色模式。
- 首页重建为半透明头部、渐变 Hero、浮动信任信息、真实分类筛选、商品卡收藏/加购、信任横幅和主题联动页脚。
- 商品服务向前台返回可选 `categoryId`、`categoryName`；中英文已知分类使用稳定显示映射。
- 页脚支付标示收敛为前台实际可用的 Stripe 托管信用卡结账。
