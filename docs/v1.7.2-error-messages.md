# v1.7.2 支付凭证上传 - 错误提示优化

**优化时间**: 2026-06-29  
**目标**: 让用户清楚了解上传失败的原因和解决方法

---

## 📋 错误类型定义

### 1. **缺少必需参数** (400)
- **错误码**: `MISSING_FIELDS`
- **错误信息**: "缺少必需参数"
- **详细说明**: "请确保已选择支付方式并上传了图片"
- **触发条件**: orderId、proofImage 或 paymentMethod 缺失

### 2. **图片格式不支持** (400)
- **错误码**: `INVALID_FILE_TYPE`
- **错误信息**: "图片格式不支持"
- **详细说明**: "仅支持 JPG、PNG、WEBP 格式的图片，请重新选择"
- **用户提示**: 💡 请使用手机截图或相册中的支付凭证图片
- **触发条件**: 上传了非 JPG/PNG/WEBP 格式的文件

### 3. **图片文件过大** (413)
- **错误码**: `FILE_TOO_LARGE`
- **错误信息**: "图片文件过大"
- **详细说明**: "图片大小不能超过 5MB，当前文件大小：X.XX MB"
- **用户提示**: 💡 可以使用微信"图片编辑"功能压缩图片后再上传
- **触发条件**: 文件大小 > 5MB

### 4. **订单不存在** (404)
- **错误码**: `ORDER_NOT_FOUND`
- **错误信息**: "订单不存在"
- **详细说明**: "找不到该订单，请确认订单号是否正确"
- **触发条件**: orderId 在数据库中不存在

### 5. **凭证已上传** (422)
- **错误码**: `PROOF_ALREADY_EXISTS`
- **错误信息**: "凭证已上传"
- **详细说明**: "该订单已上传过支付凭证，无需重复上传。如有问题请联系客服。"
- **用户提示**: 💡 如需修改凭证，请联系客服处理
- **触发条件**: 同一订单已有支付凭证记录

### 6. **图片重复使用** (409)
- **错误码**: `DUPLICATE_IMAGE`
- **错误信息**: "图片重复使用"
- **详细说明**: "该图片已被使用过，请上传新的支付凭证。每张凭证只能使用一次。"
- **用户提示**: 💡 每张支付凭证只能使用一次，请上传本次订单的支付截图
- **触发条件**: 图片哈希值与数据库中已有记录相同

### 7. **服务器错误** (500)
- **错误码**: `INTERNAL_ERROR`
- **错误信息**: "服务器错误"
- **详细说明**: "服务器处理出错，请稍后重试。如问题持续存在，请联系客服。"
- **触发条件**: 未捕获的异常

- **提示**: 小字号，浅红色背景框
