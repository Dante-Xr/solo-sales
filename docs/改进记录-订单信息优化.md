## 🎯 设计细节

### 布局
- 使用 `space-y-4` 统一间距
- 使用 `border-b` 分隔各个区域
- 使用 `flex` 布局对齐商品信息

### 商品项设计
- 左侧：商品图片（圆角）
- 中间：商品名称 + 单价×数量
- 右侧：小计金额

### 响应式
- 商品图片固定 48x48px（不缩放）
- 商品名称使用 `truncate`（长文本截断）
- 金额右对齐
